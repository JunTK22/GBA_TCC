# Cronograma detalhado

Esta pasta contém o cronograma detalhado do projeto de reprodução da
arquitetura do Game Boy Advance em FPGA.

Arquivos:

- `cronograma_detalhado.csv`: fonte simples e editável em qualquer editor de
  texto ou planilha. Use separador `;` e codificação UTF-8.
- `cronograma_detalhado.xlsx`: planilha editável para LibreOffice Calc,
  Microsoft Excel ou Google Sheets.
- `cronograma_detalhado.md`: versão de leitura rápida, com as premissas,
  marcos e atividades.
- `crono_histograma.xlsx`: crono-histograma semanal em formato semelhante ao
  Microsoft Project, com tabela de tarefas à esquerda e barras de Gantt à
  direita.
- `crono_histograma.csv`: matriz semanal editável do crono-histograma.
- `crono_histograma.md`: versão textual compacta do crono-histograma.

Premissas usadas para transformar o cronograma macro da monografia em datas:

- Mês 1 = janeiro de 2026.
- Mês 6 = junho de 2026, com o projeto na fase F3 em 2026-06-17.
- A fase F3 mantém o subsistema de memória implementado e integrado, ainda em
  validação funcional.
- As fases F4 a F6 são planejamento futuro e devem ser ajustadas conforme o
  calendário acadêmico oficial, disponibilidade de laboratório e escopo final
  aceito para a prova de conceito.

Para modificar posteriormente, edite diretamente as planilhas `.xlsx` ou os
arquivos `.csv`. As versões `.md` servem para revisão rápida em texto.
